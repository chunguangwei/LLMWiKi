# v0.9.4 发布记录

状态：验证中，尚未正式发布。线上仍为 v0.9.2。

## 用户变化

- 修复 Windows 文件历史写入和查询的路径分隔符不一致，兼容旧反斜杠键快照。
- 包含未发布的 v0.9.3 草稿修复：JEV 批次取消、恢复探针租约、MCP 网络依赖安全补丁。
- 完善文档索引、开发指南、检索/排障/发布运维手册和三语言 README。

## 验证

本地验证：前端 2,844 项通过；最终 Rust 串行回归 493 通过、2 项原有忽略。Windows 新增两项迁移兼容测试，待 CI 验证。MCP 25 项与生产前端构建在相同依赖补丁上已通过；后续改动仅 Rust、版本和文档。前一草稿验证与 Windows 失败原因见 [v0.9.3 记录](release-0.9.3.md)。本版本须等全平台 CI 通过再触发发布。

## 限制

真实 LLM / OpenRouter / 内网 Kev 未调用；Windows/Linux 安装交互未实机验收。保留原有 2 项忽略测试、Vite 动态导入提示和前端工具链 6 项中低危依赖告警（0 高/严重），MCP 审计为 0。详见 [代码审查](code-review-2026-11-16.md)。

## 下载

正式发布后使用 [v0.9.4 Release](https://github.com/chunguangwei/LLMWiKi/releases/tag/v0.9.4)，或在设置 → 关于检查更新；无需卸载或清空配置。
