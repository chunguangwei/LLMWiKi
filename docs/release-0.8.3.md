## 更新内容

- 来源列表和摄入状态按项目隔离，丢弃旧异步响应，防止切换项目时资料串入新项目。
- 批量提取等待状态就绪；缓存读取或权限检查失败时显示错误并可重试，同项目刷新保留文件树。
- 预解析和旧队列恢复双重校验来源路径，兼容自动监控、计划导入及已有相对路径任务。
- 网址下载的 60 秒超时覆盖响应头与正文；逐块执行大小限制，及时取消异常响应，并继续处理下一网址。
