# 0.8.1 发布记录

版本从 0.8.0 提升为 0.8.1，保留大版本、应用 identifier 和更新签名配置。

## 用户可见变化

- 导入包完整预检路径、目标符号链接与文件校验和，拒绝未列入清单的文件；内容先暂存，校验通过后逐文件原子替换。I/O 故障仍可能导致部分文件已提交，这不是整个项目级事务。
- 新包保存根目录的 schema.md 和 purpose.md；旧包缺少 schema 时要求导入已有项目，避免静默丢失自定义规则。
- 刷新提交与项目写入、编辑器保存协调；页面内容已改变或删除时放弃过期结果。模型错误或无效状态按失败处理，失败检查在下一次扫描重试。
- 新折页 W Logo，包含 SVG 与全平台图标、浏览器和扩展资产。

## 回归证据

- 修改实现前：6 项 Rust 包回归用例全部失败；刷新管线有 7 项失败，另分别复现了调度器错误统计与失败重试问题。
- 修改后：包导入/导出 7 项通过，刷新相关 26 项通过。
- 前端全量 mock：205 个文件，2800 项通过；MCP：25 项通过。
- `npm run build:desktop` 通过（包括类型检查、MCP 打包和 Vite 构建）。
- npm audit：0 个已知漏洞。
- Rust 全量测试：475 项通过、2 项原有忽略测试；含本地 HTTP 监听的测试在沙箱外运行。Rust check 通过。
- 独立复核发现归档 Unicode/大小写别名与嵌套 wiki 目录锁两项问题，均新增测试观察失败后修复，并通过最终全量测试。
- 归档名称按 NFC 和 Unicode case folding 做跨平台冲突校验；歧义名称即使在区分大小写系统上也会拒绝。
- 安装包、更新签名、latest.json 与扩展 ZIP 在推送标签后由 GitHub Actions 构建并校验。

真实外部 LLM 服务与人工桌面交互未在此轮验收；跨平台安装包由 GitHub Actions 构建。
