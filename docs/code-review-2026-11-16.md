## Windows CI 追加发现

启用全量 CI 后暴露此前只编译未运行的 7 个失败：6 个文件历史用例在 Windows 返回空记录，根因为写入相对路径含 `/`、canonicalize 后查询含 `\`，旧 FNV 键不一致；另 1 个绝对路径测试错误地假定 `/tmp/...` 在 Windows 为完整绝对路径。

v0.9.3 草稿构建已取消。v0.9.4 统一 Windows 键为正斜杠，并在新键不存在时复用旧原生反斜杠键；新增 Windows 单旧存储、双存储合并与恢复 ID 兼容测试。双存储在锁内按时间合并并按 ID 去重，写入同步后的同目录临时文件原子替换成功后才删除旧存储。Unix 文件名中的反斜杠不做替换，保留合法文件名语义。绝对路径校验实现不变，修正测试的平台预期。

全量本地并行测试还暴露 JEV 本机服务器连接等待偶发超时；代理测试会修改进程级 HTTP_PROXY/NO_PROXY。CI 与发布验证改为 Rust 串行测试，隔离该环境变量干扰，不改生产代理行为。
